Para quem é — e o que você vai saber fazer ao final

Este manual é para quem escreve trabalhos com muitas referências — artigo, dissertação, tese, revisão sistemática — e ainda guarda PDFs em pastas e digita a lista de referências à mão. Não exige conhecimento prévio: começa na instalação e termina com o fluxo completo de uma revisão.

Ao final, você vai conseguir

  • Capturar qualquer referência com um clique, por DOI ou a partir de um PDF.
  • Organizar centenas de itens em coleções, etiquetas e pesquisas salvas — sem duplicatas.
  • Ler e anotar no leitor integrado e transformar destaques em notas citáveis.
  • Citar no Word, LibreOffice ou Google Docs no estilo ABNT, com a lista gerada sozinha.
  • Exportar para LaTeX, Obsidian, ASReview e Rayyan; colaborar em bibliotecas de grupo.
Regra

Todo passo aparece com o caminho de menu exato e uma captura de tela da versão atual (Zotero 10). Os nomes de menu estão em português, conforme a interface em pt-BR.

Armadilha

O que a regra evita: o erro que quase sempre parece economia de tempo — copiar uma referência à mão, salvar um PDF sem item pai, editar a lista final no Word.

Este manual cuida da ferramenta. O que decidir em cada etapa da pesquisa está em Metodologia da pesquisa científica; o que delegar à inteligência artificial, em Uso de IA na pesquisa científica. Termos sublinhados abrem a definição do glossário.

Introdução1 de 2

Por que um gerenciador de referências

«Salvar o PDF na pasta» funciona até a vigésima referência. Depois disso, cada mudança de estilo, cada obra acrescentada, cada correção de autor vira retrabalho manual — e a lista final deixa de bater com o texto.

Pasta de PDFs + lista digitada
  • Metadados vivem no nome do arquivo: «artigo_final_v3.pdf».
  • Cada citação é digitada; cada mudança de estilo é refeita à mão.
  • Texto e lista se dessincronizam na primeira revisão.
  • Anotações ficam presas no PDF, sem busca.
  • Não há como compartilhar a base com o coautor.
Gerenciador de referências
  • Cada obra é um item com metadados, PDF, notas e etiquetas.
  • A citação entra no texto pelo plugin; a lista é gerada e regenerada sozinha.
  • Trocar de estilo (ABNT → APA) é um clique — o documento inteiro se atualiza.
  • Destaques e notas são pesquisáveis e citáveis.
  • Biblioteca sincronizada e compartilhável em grupo.
Regra

A lista de referências nunca é editada à mão no documento final. Corrige-se o item no gerenciador e regenera-se. Este é o princípio que justifica todo o resto do manual.

Instalar1 de 6

Baixar: dois programas, não um

A página de download oferece o Zotero (o programa) e o Zotero Connector (a extensão do navegador). Os dois trabalham juntos: o Connector captura, o programa guarda. Instale os dois.

  1. Abra zotero.org/download.
  2. A página detecta o sistema; se precisar de outra versão (ARM, 32 bits), use «Other platforms».
  3. Baixe o instalador do programa.
  4. Instale o Connector no navegador que você usa para pesquisar (Chrome, Firefox, Edge; no Safari ele já vem com o programa).
Armadilha

Instalar só o Connector. Sem o programa aberto, o Connector não tem para onde enviar o que captura. Baixe sempre do site oficial; versões de lojas e repositórios de distribuições Linux não são mantidas pelo projeto.

Criar a conta e ativar a sincronização

A conta em zotero.org é gratuita e serve para três coisas: sincronizar a biblioteca entre computadores, ter uma cópia dos dados na nuvem e participar de grupos. A sincronização de dados (metadados, notas, etiquetas) é gratuita e ilimitada; só os arquivos anexos têm cota.

  1. Crie a conta em zotero.org/user/register.
  2. No Zotero: Editar (Windows/Linux) ou Zotero (macOS) → Configurações → Conta.
  3. Entre com usuário e senha; marque «Sincronizar automaticamente».
  4. Em «Sincronização de arquivos», decida se anexos sobem para o Zotero Storage (300 MB grátis) — detalhes na Parte 7.
  5. Clique no ícone de sincronizar (seta circular) no canto superior direito.
Armadilha

Sincronizar duas bibliotecas diferentes na mesma conta. O Zotero mescla, não substitui: o resultado é uma biblioteca com tudo dos dois lados. Se um computador tem lixo, limpe antes de ligar a sincronização nele.

Capturar3 de 6

Arrastar um PDF — e quando adicionar à mão

Arrastar PDF

  1. Arraste o arquivo para a lista de itens (ou «Adicionar anexo» → «Arquivo…»).
  2. O Zotero lê o DOI ou o título dentro do PDF e cria o item pai com os metadados; o PDF fica como anexo.
  3. Se não conseguir, o PDF fica sozinho: clique com o botão direito → «Recuperar metadados do PDF».
  4. Se ainda assim falhar, crie o item pela varinha e arraste o PDF sobre ele.
Armadilha

PDF sem item pai. Um anexo solto não tem autor, ano nem título — não pode ser citado e some da lista de referências. Todo PDF precisa de um pai; «Sem coleção» e a busca por «anexo independente» ajudam a achar os órfãos.

Adicionar manualmente (último recurso)

  1. «Novo item» (ou Ctrl+Shift+N) → escolha o tipo: livro, capítulo, tese, norma, relatório, legislação…
  2. Preencha autor (Sobrenome, Nome — um por linha), título, ano, editora ou instituição, local.
  3. Para normas e leis, use os tipos «Norma» e «Legislação»; para trabalhos acadêmicos, «Tese»; o estilo ABNT trata cada tipo de forma diferente.

Importar o arquivo exportado de uma base (RIS, BibTeX, CSV)

Para revisões sistemáticas, o caminho correto não é o Connector: é exportar o resultado completo da busca a partir da base, com data e string registradas, e importar o arquivo. Assim o total importado bate com o total registrado no PRISMA.

Web of ScienceExport → «Other file formats» → «Tab delimited» ou RIS; «Full record»RIS · WoS tagged
PubMedSend to → Citation managerNBIB/RIS

  1. Crie uma coleção com a base e a data: busca_scopus_2026-09-08.
  2. Arquivo → Importar… → «Um arquivo (BibTeX, RIS, Zotero RDF etc.)» → escolha o arquivo.
  3. Marque «Colocar as coleções e os itens importados em uma nova coleção» e, para triagem, desmarque o download de PDFs.
  4. Confira o total importado contra o total da base. Diferença = registro corrompido ou limite de exportação da base.
Regra

Uma coleção por base e por data. Nunca misture o resultado bruto da busca com a biblioteca de leitura: a deduplicação (slide 19) acontece depois, e o número de cada etapa precisa continuar verificável.

Formatos aceitos: RIS, BibTeX/BibLaTeX, CSL JSON, Zotero RDF, EndNote XML, RefWorks, Web of Science tagged, PubMed XML, MODS, MARC, entre outros. CSV só via conversão (por exemplo, para RIS) ou plugin.

Capturar5 de 6

Encontrar o texto completo: PDF aberto e acesso institucional

Um item sem PDF é uma referência que você ainda não leu. O Zotero procura o arquivo em duas frentes: a página do DOI (que funciona se você tem acesso pela universidade) e o Unpaywall, base de cópias legais em acesso aberto.

  • Faça isso conectado à rede da universidade (ou pelo proxy/VPN): a primeira tentativa é a página do editor.
  • Selecione muitos itens de uma vez; o Zotero respeita um intervalo entre pedidos e para se a editora bloquear.
  • Sem acesso e sem cópia aberta, o resultado é «não disponível» — peça pelo serviço de comutação da biblioteca, não por sites piratas.
Acesso aberto

O Unpaywall lista a versão publicada, a aceita (postprint) ou a submetida (preprint), nessa ordem. Ao citar, verifique se a paginação do PDF encontrado corresponde à do artigo publicado.

Organizar1 de 5

Coleções e subcoleções: listas, não pastas

Uma coleção funciona como uma playlist: o mesmo item pode estar em várias, e removê-lo de uma não o apaga da biblioteca. «Minha biblioteca» sempre mostra tudo.

estrutura sugerida para um projeto de pesquisa
Dissertação 2026/
├── 0 Buscas brutas/            # uma subcoleção por base e data; não mexer
│   ├── scopus_2026-09-08
│   └── wos_2026-09-08
├── 1 Triagem/                  # incluídos · excluídos · dúvida
├── 2 Leitura/                  # o que está sendo lido (etiqueta «lido»)
├── 3 Capítulos/                # um por capítulo — o item pode estar em vários
└── 4 Normas e legislação/
  • Item em coleção pai não aparece automaticamente nas subcoleções, nem o contrário (opção em Configurações → Geral → «Mostrar itens de subcoleções»).
  • Apagar uma coleção não apaga os itens — salvo se escolher «Excluir coleção e itens…».
  • Na versão 10, selecione várias coleções com Ctrl para ver os itens de todas juntas.
Armadilha

Coleção por tema como única organização. Temas se sobrepõem e a árvore vira labirinto. Use coleções para etapas e capítulos; para tema, use etiquetas.

Busca, busca avançada e pesquisas salvas

A caixa de busca filtra a lista enquanto você digita — por título, autor e ano; por «Todos os campos e etiquetas»; ou por «Tudo», que inclui o texto dos PDFs e das notas. A busca avançada combina condições; salva, vira uma coleção que se atualiza sozinha.

  1. Clique no ícone de filtro ao lado da caixa de busca (ou Editar → Busca avançada).
  2. Monte as condições: Etiqueta é «status:ler» E Data de adição é nos últimos 30 dias.
  3. Na versão 10, agrupe condições (E / OU aninhados) e busque sem se importar com acentos: «cafe» encontra «café».
  4. «Salvar pesquisa» → dê um nome; ela aparece no painel esquerdo com ícone próprio.

Armadilha

Os PDFs dos incluídos ficam no grupo (cota do dono) para que todos leiam e anotem o mesmo arquivo — as anotações de cada um aparecem com o nome do autor.

Glossário

Tudo que aparece no manual sem ser explicado no próprio slide. Termos sublinhados no texto abrem estas definições.

Itens, formatos e identificadores

Item
O registro de uma obra no Zotero: tipo, metadados, anexos, notas, etiquetas e relações.
Item pai · anexo
O registro bibliográfico; o arquivo (PDF, EPUB, página salva) ou link ligado a ele. Anexo sem pai não é citável.
Metadado
Cada campo que descreve a obra — autor, título, periódico, ano, volume, páginas, DOI. É o que o estilo formata.
DOI
Digital Object Identifier: identificador persistente de um documento; resolve em doi.org e na Crossref.
ISBN · PMID · arXiv
Identificador de livro; identificador de artigo no PubMed; identificador de preprint no arXiv.
RIS
Formato de intercâmbio bibliográfico em texto, lido por praticamente todas as bases e ferramentas de triagem.
BibTeX · BibLaTeX
Formatos de banco de referências do LaTeX; cada entrada tem uma chave de citação.
CSL JSON
Representação em JSON dos campos de um item, exatamente como o processador de citações os lê.
Chave de citação
Identificador curto de uma entrada BibTeX, como silva2024automacao; com o Better BibTeX, é estável.
CSL
Citation Style Language: linguagem aberta em que os estilos de citação (ABNT, APA…) são escritos; usada por Zotero, Pandoc e outros.
Estilo autor-data · numérico · nota
Sistemas de citação: (AUTOR, ano); [n]; nota de rodapé. A ABNT admite os dois primeiros.
PDF de acesso aberto
Cópia legal e gratuita do texto — publicada, aceita (postprint) ou submetida (preprint).
Unpaywall
Base que localiza cópias de acesso aberto a partir do DOI; o Zotero a consulta em «Encontrar texto completo».

Organização, programa e serviços

Coleção · subcoleção
Agrupamento de itens semelhante a uma playlist: o mesmo item pode estar em várias; remover não apaga.
Etiqueta (tag)
Rótulo transversal atribuído a itens e anotações; até nove podem ter cor e tecla (1–9).
Pesquisa salva
Busca avançada guardada como coleção que se atualiza sozinha.
Nota filha · nota independente
Nota ligada a um item; nota solta na biblioteca, para sínteses de vários itens.
Anotação
Destaque, sublinhado, nota, texto, área ou tinta feita no leitor; fica no banco do Zotero, não no arquivo.
Connector
Extensão do navegador que reconhece a página e envia metadados e PDF ao programa.
Tradutor (translator)
Script que ensina o Connector a ler um site ou o Zotero a importar um formato.
Plugin
Extensão instalada no programa (arquivo .xpi); tem acesso total à biblioteca e ao computador.
Cópia rápida (Quick Copy)
Copiar itens já formatados no estilo escolhido: Ctrl+Shift+A (citação), Ctrl+Shift+C (bibliografia) ou arrastar.
Sincronização de dados · de arquivos
Envio dos itens, notas e anotações ao zotero.org (gratuito, ilimitado); envio dos anexos (cota de 300 MB ou WebDAV).
WebDAV
Protocolo de acesso a arquivos por HTTP; permite guardar os anexos num servidor próprio.
Zotero Storage
Armazenamento de anexos do próprio Zotero; obrigatório para arquivos de grupos.
Grupo
Biblioteca compartilhada com membros, papéis e permissões; privado ou público.
Pasta de dados
Diretório com zotero.sqlite e storage/: é a biblioteca inteira; é o que se copia no backup.
Better BibTeX (BBT)
Plugin que gera chaves estáveis e mantém arquivos .bib atualizados automaticamente.
ZoteroBib
Gerador de bibliografias no navegador (zbib.org), sem conta nem instalação.
API
Interface em api.zotero.org para ler e escrever na biblioteca por programa, com chave de acesso.
